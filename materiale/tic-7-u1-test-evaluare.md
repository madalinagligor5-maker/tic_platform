# Item 1. Alege un singur răspuns corect pentru fiecare întrebare.
Ce înseamnă tehnoredactarea unui document?
- scrierea cât mai rapidă a textului
- corectarea greșelilor de ortografie
* aranjarea textului în pagină, ca documentul să fie îngrijit și ușor de citit
- trimiterea documentului prin e-mail
Explicație: Editarea înseamnă scrierea și modificarea textului; tehnoredactarea înseamnă aranjarea lui în pagină.

Care dintre următoarele aplicații este un editor de texte simplu, care lucrează doar cu fișiere .txt?
* Notepad
- Microsoft Word
- LibreOffice Writer
- Google Docs

Ce extensie are un document salvat în formatul obișnuit al aplicației Microsoft Word?
- .txt
- .pptx
- .odt
* .docx

Ce element al ferestrei Word arată numărul paginii, numărul de cuvinte și panoramarea (zoom)?
- bara de titlu
- rigla
* bara de stare
- bara de acces rapid

Ce tastă șterge caracterul aflat în stânga cursorului?
- Delete
* Backspace
- Home
- End

Ce combinație de taste aliniază un paragraf la centru?
- Ctrl + L
- Ctrl + J
- Ctrl + R
* Ctrl + E

Ce face combinația de taste Ctrl + Enter?
- salvează documentul
* începe o pagină nouă
- aliniază textul stânga-dreapta
- creează un document nou
Explicație: Ctrl + Enter inserează o întrerupere de pagină; nu apeși Enter de multe ori.

- tipărești documentul

- schimbi orientarea paginii
