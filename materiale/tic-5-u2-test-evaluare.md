```quiz puncte=24
# Item 1. Alege un singur răspuns corect.
Ce este sistemul de operare?
- un dispozitiv periferic de intrare
* un ansamblu de programe care face legătura dintre hardware și utilizator
- un program de desen inclus în Windows
- o componentă din interiorul unității centrale

Care dintre următoarele este un sistem de operare cu interfață text?
* MS-DOS
- Windows
- Android
- macOS
Explicație: La MS-DOS comenzile se scriu; celelalte au interfață grafică.

Ce buton apeși ca fereastra să devină o pictogramă pe bara de activități?
- butonul de închidere (✕)
- butonul de maximizare (□)
* butonul de minimizare (–)
- butonul de control

Ce extensie are un fișier audio?
- .txt
- .jpg
- .avi
* .mp3

Folderul care nu are folder părinte se numește:
* rădăcină
- subfolder
- extensie
- cale

Ce combinație de taste folosești ca să decupezi un fișier, pentru a-l muta?
- Ctrl + C
* Ctrl + X
- Ctrl + A
- Alt + F4
```

```quiz puncte=24
# Item 2. Rezolvă situațiile. Alege un singur răspuns corect.
Fișierul `vara.jpg` se află în folderul `FOTO`, care este în folderul `Lucru`, pe unitatea `D:`. Care este calea lui?
- `vara.jpg\FOTO\Lucru\D:`
- `D:\FOTO\Lucru\vara.jpg`
* `D:\Lucru\FOTO\vara.jpg`
- `D:\Lucru\vara.jpg\FOTO`
Explicație: Calea pornește de la rădăcină și coboară pe rând prin foldere, până la fișier.

Care dintre următoarele poate fi numele unui fișier în Windows?
- `tema?.txt`
- `tema:TIC.txt`
- `tema*TIC.txt`
* `tema_TIC.txt`
Explicație: Caracterele `\ / : * ? " < > |` nu sunt permise în nume.

Pentru calea `C:\Scoala\TIC\Unitatea2\fereastra.png`, folderul `TIC` este:
- rădăcina
- fișierul căutat
* folderul părinte al folderului `Unitatea2`
- extensia fișierului

Ai șters din greșeală un fișier de pe hard disk. Cum îl recuperezi?
* deschizi Coșul de reciclare, dai clic dreapta pe fișier și alegi Restaurare
- apeși Ctrl + V în folderul în care era fișierul
- repornești calculatorul
- deschizi File Explorer și apeși Ctrl + A

Vrei să selectezi fișierele 1, 4 și 7 dintr-o listă. Ce faci?
- dai clic pe primul, ții apăsat Shift și dai clic pe ultimul
* dai clic pe primul, ții apăsat Ctrl și dai clic pe fiecare dintre celelalte
- apeși Ctrl + A
- dai dublu clic pe fiecare fișier
Explicație: Cu Shift selectezi fișiere aflate unul după altul; pentru fișiere răzlețe folosești Ctrl.

Tragi cu mouse-ul un fișier din folderul `C:\Lucru` pe stickul `E:`. Ce se întâmplă?
- fișierul se mută pe stick și dispare din `C:\Lucru`
- fișierul se șterge definitiv
- fișierul ajunge în Coșul de reciclare
* fișierul se copiază pe stick și rămâne și în `C:\Lucru`
Explicație: Când tragi un fișier pe altă unitate de disc, Windows îl copiază, nu îl mută.
```

```quiz puncte=12
# Item 3. Alege TOATE răspunsurile corecte (fiecare întrebare are mai multe răspunsuri corecte).
Care sunt funcții ale sistemului de operare?
* controlează accesul la hardware
* oferă o interfață prin care dai comenzi și pornești aplicații
- tipărește automat toate documentele
* administrează datele
- desenează imaginile cerute de utilizator

Care extensii sunt ale unor fișiere imagine?
* .png
- .mp3
* .jpg
- .txt
* .gif

Care sunt opțiuni ale butonului Alimentare (Power) din meniul Start?
- Minimizare
* Închidere (Shut down)
* Repornire (Restart)
* Repaus (Sleep)
- Restaurare
```

```adevarat-fals puncte=15
# Item 4. Stabilește dacă afirmațiile sunt adevărate (A) sau false (F).
A: Fără sistem de operare, un calculator nu poate fi folosit.
F: Un fișier șters de pe stick ajunge în Coșul de reciclare. | De pe stick, fișierul este șters definitiv.
A: Un folder poate conține fișiere și alte foldere.
F: La copiere, fișierul dispare din locul vechi. | Fișierul dispare din locul vechi la mutare; la copiere rămâne în ambele locuri.
A: Combinația de taste Alt + F4 închide fereastra activă.
```

# Item 5. Completează spațiile libere.
Partea din numele unui fișier aflată după punct se numește [extensie|extensia]. Un folder aflat în alt folder se numește [subfolder].

Drumul de la rădăcină până la un fișier, de exemplu `C:\Lucru\MUZICA\jazz.mp3`, se numește [cale|calea].

Programul din Windows cu care lucrăm cu fișiere și foldere se numește [File Explorer|Explorer|Explorer de fișiere]. Fereastra care primește comenzile tale se numește fereastra [activă].
