```quiz puncte=20
# Item 1. Alege un singur răspuns corect pentru fiecare întrebare.
Ce reprezintă `www.exemplu.ro` în adresa `https://www.exemplu.ro/clase/a8.html`?
- Protocolul
* Domeniul
- Calea către pagină
- Numele fișierului paginii

Cum se numește calculatorul conectat permanent la internet, pe care sunt păstrate paginile unui site?
- Browser
- Motor de căutare
* Server web
- Editor de cod

Ce înseamnă un editor WYSIWYG?
- Un editor în care scrii doar cod HTML, fără să vezi rezultatul
- Un program care publică automat orice fișier pe internet
- Un browser care afișează codul sursă al paginilor
* Un editor vizual în care pagina arată în timpul lucrului așa cum va arăta publicată

Zona de jos a unei pagini web, cu datele de contact și drepturile de autor, se numește:
- antet (*header*)
- meniu de navigare
- bară laterală

Ce este harta unui site?
```

```quiz puncte=20
# Item 2. Citește codul HTML și alege un singur răspuns corect.
Ce conține secțiunea `<head>` a unei pagini HTML?
- Tot textul și toate imaginile care apar pe ecran
* Informații despre pagină, de exemplu codificarea și titlul din fila browserului
- Doar meniul de navigare al site-ului
- Subsolul paginii

Ce rol are atributul `alt` din `<img src="pelican.jpg" alt="Un pelican pe apă" width="300">`?
- Stabilește lățimea imaginii
- Indică fișierul imagine
* Oferă textul alternativ, afișat dacă imaginea nu se încarcă și citit de cititoarele de ecran
- Aliniază imaginea în centrul paginii

Care variantă este scrisă corect, cu etichetele închise în ordinea inversă deschiderii?
- `<p><strong>Delta</p></strong>`
- `<strong><p>Delta</strong></p>`
- `<p>Delta<strong></p>`
* `<p><strong>Delta</strong></p>`

Ce efect are codul `<p style="color: blue; text-align: center;">Bine ați venit!</p>`?
- Un titlu principal albastru, aliniat la stânga
* Un paragraf cu text albastru, centrat
- Un paragraf cu fundal albastru, aliniat la dreapta
- O legătură albastră către pagina de start

Pagina `index.html` și imaginea `castel.jpg` se află în același folder. Ce cod afișează imaginea cu lățimea de 250 de pixeli?
- `<img href="castel.jpg" width="250">`
- `<image src="castel" size="250">`
* `<img src="castel.jpg" alt="Castelul" width="250">`
- `<a src="castel.jpg" width="250">`
```

```quiz puncte=15
# Item 3. Alege un singur răspuns corect pentru fiecare situație (Google Sites).
Ai publicat site-ul, apoi ai adăugat o imagine nouă. Ce faci ca imaginea să apară și în varianta online?
- Nimic, Google Sites publică singur orice modificare
- Ștergi site-ul și îl creezi din nou
* Apeși din nou butonul „Publicați”
- Apeși „Previzualizare”

Vrei ca paginile „Robotică” și „Ecologie” să apară în meniu într-o listă derulantă sub „Proiecte”. Ce faci?
* Le faci subpagini ale paginii „Proiecte”, din fila „Pagini”
- Le ascunzi din navigare
- Le pui pe fiecare într-un site separat
- Scrii numele lor în subsolul site-ului

Patru colegi construiesc împreună un site, fiecare câte o pagină. Ce face proprietarul site-ului?
- Le trimite parola contului lui
* Îi adaugă ca „Editori” prin „Distribuiți cu alte persoane”
- Le trimite linkul de vizualizare al site-ului publicat
- Face câte o copie a site-ului pentru fiecare coleg

Vrei să pui pe pagina despre Castelul Bran o fotografie a castelului. Ce alegere respectă drepturile de autor?
- Copiezi prima imagine găsită pe internet, fără sursă
- Folosești fotografia unui coleg, fără să-l întrebi
- Decupezi imaginea dintr-un site de știri și scrii că e a ta
* Folosești o imagine liberă de drepturi (de exemplu, de pe Wikimedia Commons) și scrii sursa
```

```quiz puncte=15
# Item 4. Alege TOATE răspunsurile corecte (fiecare întrebare are mai multe răspunsuri corecte).
Care dintre următoarele etichete HTML NU au etichetă de închidere?
* `<br>`
- `<p>`
* `<img>`
- `<h1>`

Care informații NU trebuie publicate pe site-ul clasei?
* Adresa de acasă a unui elev
* Numărul de telefon al unui coleg
- Programul activităților clubului
* Fotografii cu colegii, fără acordul lor

Care sunt criterii după care analizezi calitatea unui site?
* Informația este corectă, actualizată și are autor și surse
* Meniul este clar și legăturile funcționează
- Pagina are cât mai multe culori și animații
* Site-ul se adaptează și pe telefon (design *responsive*)
```

```adevarat-fals puncte=10
# Item 5. Stabilește dacă afirmațiile sunt adevărate (A) sau false (F).
A: Un site web este un grup de pagini legate între ele, cu o temă comună, sub același domeniu.
F: Tasta Enter apăsată în codul HTML creează un paragraf nou în pagina afișată. | Spațiile și Enter din cod nu se văd; un paragraf nou se face cu eticheta `<p>`.
A: Litera „s” din `https` arată că legătura cu site-ul este securizată.
F: În Google Sites, subsolul trebuie creat separat pe fiecare pagină. | Subsolul site-ului apare automat pe toate paginile.
A: Paginile web sunt scrise în limbajul HTML, iar aspectul lor se stabilește cu CSS.
```
