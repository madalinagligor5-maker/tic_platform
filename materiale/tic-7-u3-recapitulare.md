## Recapitulare

```cartonase
# Cuvinte-cheie
Aplicație colaborativă = mai multe persoane lucrează simultan la același fișier, prin internet
Cloud = stocarea fișierelor pe serverele unei firme, accesibile de oriunde
Editor / Comentator / Vizualizator = drepturile la partajare
Modul Sugerare = modificări propuse, pe care autorul le acceptă sau le respinge
Istoricul versiunilor = variantele mai vechi ale fișierului, care pot fi restabilite
GIS = sistem informatic geografic, care afișează pe hartă date legate de locuri
Strat = set de date al hărții, care poate fi afișat sau ascuns
```

## Proiect de recapitulare: „Ghidul clasei pentru excursie”

Lucrați în echipe de câte patru:

1. Un elev creează în Drive folderul echipei și îl **distribuie** colegilor.
2. Faceți împreună un **Document Google** cu programul excursiei, regulile și lista de bagaje. Folosiți **comentarii** cu **@nume** pentru întrebări.
3. Faceți o **Prezentare Google** de 5 diapozitive, câte unul fiecare, despre locurile vizitate.
4. Faceți o hartă în **Google My Maps** cu traseul (linie) și opririle (puncte).
5. Distribuiți totul profesorului ca **Comentator** și descărcați documentul ca **PDF**.
