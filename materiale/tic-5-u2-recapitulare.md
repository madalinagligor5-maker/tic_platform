## Recapitulare

```quiz
# Alege răspunsul corect.
Ce program interpretează comenzile utilizatorului și face legătura dintre echipamentele fizice și utilizator?
- programele de aplicații
* sistemul de operare
- programele accesorii

Care sunt operații principale cu fișiere și foldere?
- căutarea, procesarea, partajarea
* crearea, salvarea, copierea, mutarea
- ștergerea, curățarea, segmentarea, memorarea
- tipărirea, scanarea, procesarea, editarea

Care este un nume corect de fișier în Windows 10?
* `ExperimentBun!_1.txt`
- `ExperimentBun?_1.txt`
- `ExperimentBun->1.txt`
```

## Autoevaluare

Timp de lucru: 15 minute. Fiecare aplicație valorează 30 de puncte, plus 10 puncte din oficiu.

```quiz
# 1. Alege răspunsul corect.
Un program din bara de activități se deschide cu:
* un clic
- dublu clic

Un fișier aflat în Coșul de reciclare:
* poate fi recuperat
- nu poate fi recuperat

O fereastră din Windows are forma:
* dreptunghiulară
- rotundă
```

```adevarat-fals
# 2. Structura de foldere
A: Calea C:\Scoala\Mate\cerc.jpg arată că fișierul cerc.jpg este în folderul Mate.
A: Un fișier cu extensia .jpg este o imagine.
F: Un fișier cu extensia .mp3 este un film. | .mp3 este un fișier audio; filmele au extensii ca .mp4 sau .avi.
```
