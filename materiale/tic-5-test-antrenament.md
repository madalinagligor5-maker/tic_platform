## Cum funcționează

- Ai **6 itemi** de tipuri diferite și **25 de minute** recomandate.
- Răspunde la toți itemii, apoi apasă **Predă testul**. Primești punctajul, **nota** și corectura fiecărui item.
- Poți relua testul de câte ori vrei. Dacă ești în contul de elev, profesorul vede rezultatul primei încercări.

```quiz puncte=20
# Alege răspunsul corect.
Ce componentă este „creierul” calculatorului?
- Placa video
* Procesorul (CPU)
- Hard diskul
Explicație: Procesorul execută instrucțiunile programelor.

Ce memorie se golește când închidem calculatorul?
* Memoria RAM
- Hard diskul
- Stick-ul USB
Explicație: RAM este memorie volatilă.

Care sunt dispozitive de ieșire? (mai multe răspunsuri)
* Monitorul
* Imprimanta
- Tastatura
* Boxele
Explicație: Tastatura introduce date, deci este dispozitiv de intrare.

Ce program ne ajută să găsim informații pe internet după cuvinte-cheie?
- Sistemul de operare
* Un motor de căutare
- Editorul grafic
Explicație: Google, Bing sau DuckDuckGo sunt motoare de căutare.
```

```adevarat-fals puncte=15
A: Sistemul de operare gestionează resursele calculatorului. | Exemplu: Windows, Linux, macOS.
F: Un folder poate conține doar fișiere, nu și alte foldere. | Un folder poate conține și alte foldere (subfoldere).
A: Extensia unui fișier ne arată de obicei tipul lui. | De exemplu .png este o imagine, .docx un document.
F: Este sigur să îți spui parola prietenilor de pe internet. | Parola nu se spune nimănui, în afară de părinți.
A: Monitorul se așază la 45–70 cm de ochi. | Așa se reduce oboseala ochilor.
```

```categorii puncte=15
# Hardware sau software?
Hardware: procesor, mouse, memorie RAM, imprimantă
Software: sistemul de operare, browserul, editorul grafic, un joc
```

```ordonare puncte=10

Aleg folderul și scriu numele fișierului
```
