## Recapitulare

```cartonase
# Cuvinte-cheie
Pagină web = document afișat de browser, cu text, imagini și hiperlinkuri
Site web = grup de pagini legate între ele, sub același domeniu
URL = adresa unică a unei pagini web
Server web = calculatorul care păstrează paginile și le trimite browserelor
HTML = limbajul în care sunt scrise paginile web
WYSIWYG = ce vezi este ce obții: construiești vizual, fără cod
Harta site-ului = schema cu toate paginile și legăturile dintre ele
```

```categorii
# Ce face eticheta HTML?
h1: titlul cel mai mare
p: paragraful
a: legătura
img: imaginea
```

```quiz
# Alege răspunsul corect.
Ce faci după ce ai modificat un site Google deja publicat?
* apeși din nou Publicați
- nimic
- creezi alt site

Unde adaugi o subpagină în Google Sites?
- în fila Teme
* în fila Pagini

```

```adevarat-fals
A: Pe un site public folosești doar imagini proprii sau libere de drepturi.
F: Constructorii de site-uri cer să scrii codul HTML. | Construiești vizual; codul se scrie automat.
A: Subsolul site-ului apare pe toate paginile.
```

## Proiect de recapitulare: „Ghidul clasei a VIII-a”

În echipe de câte patru, realizați un site Google cu:

1. **Harta site-ului** desenată pe hârtie: Acasă și cel puțin patru pagini (Profesorii noștri, Activități, Sfaturi pentru Evaluarea Națională, Liceele din oraș).
2. O **temă** comună și **antete** asemănătoare pe toate paginile.
3. Pe pagina „Liceele din oraș”: o **foaie de calcul** încorporată (din Unitatea 1) cu liceele și mediile de admitere și o **hartă**.
4. Pe pagina de start: **butoane** către toate paginile și un **formular** „Ce v-a plăcut cel mai mult?”.
5. Imagini **libere de drepturi**, cu surse, fără date personale.
6. Verificare pe telefon și **publicare**.
