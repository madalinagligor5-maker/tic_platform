## Recapitulare

```quiz
# Alege varianta corectă.
Internetul este o rețea de calculatoare la nivel:
* mondial
- național
- continental

Ce serviciu permite trimiterea și primirea de mesaje electronice?
- VoIP
* e-mail
- FTP
```

```completare
# Completează.
Pentru a accesa informațiile de pe web folosești un program numit [browser|program de navigare]. Serviciul pentru transferul de fișiere se numește [FTP], iar cel pentru conectarea la un calculator aflat la distanță se numește [Telnet].
```

```adevarat-fals
F: Toate materialele de pe internet se pot folosi gratuit, în orice scop. | Ele sunt protejate de drepturile de autor.
F: Google, Bing, Yahoo, Windows și Edge sunt motoare de căutare. | Windows este un sistem de operare, iar Edge este un browser.
A: Poți salva datele găsite la căutare, dar folosirea lor respectă drepturile de autor.
```

```categorii
# Cuvinte legate de internet: sortează-le.
Servicii: e-mail, WWW, FTP, Telnet, IRC
Navigare: browser, hiperlink, URL, site, pagină
```

## Interevaluare

Rezolvă, apoi verifică-te împreună cu un coleg. Timp de lucru: 15 minute.

```quiz
# 1. Care site este potrivit vârstei tale?
Alege site-ul potrivit pentru tine:
* un site cu jocuri educaționale recomandat de profesor
- un site de știri despre accidente și dezastre
- un site de socializare unde vorbești cu necunoscuți
```

```adevarat-fals
# 2. Un site are paginile A, B, C și D. Din A ai link spre B și C, din B spre D, iar din C spre A.
A: Din pagina A se poate ajunge în pagina D, trecând prin B.
F: Din pagina C se poate ajunge direct în pagina D. | Din C ai link doar spre A; ajungi în D pe drumul C → A → B → D.
A: Cel mai scurt drum de la A la D este A → B → D.
```

```categorii
# 3. Care aplicații sunt motoare de căutare?
Motor de căutare: Bing, Google
Nu este motor de căutare: Paint, File Explorer, WordPad, Notepad
```
