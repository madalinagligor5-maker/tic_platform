## Recapitulare

```completare
# Completează.
Cuvântul englezesc care înseamnă „zgârietură” și este și numele unui mediu de programare grafic este [Scratch]. Blocurile de decizie se găsesc în categoria [Control].
```

```categorii
# Care blocuri sunt operatori relaționali?
Operator relațional: a < b, a > b, a = b
Alt operator: a + b, a mod b, a și b
```

```quiz
# Alege răspunsul corect.
Un script începe cu „când tasta spațiu este apăsată” și conține doar blocuri de mișcare și „spune”. Ce fel de script este?
* secvențial (liniar), pornit de apăsarea tastei Spațiu
- decizional, pornit de steagul verde
- decizional, pornit de tasta Spațiu

Ce valoare are expresia (7 + 3) * 2 > 15?
* Adevărat
- Fals
Explicație: (7 + 3) * 2 = 20, iar 20 > 15.
```
