## Ce vei învăța azi

- ce este un **procesor de text** și la ce folosește;
- diferența dintre **formatarea caracterelor** și **formatarea paragrafelor**;
- cum aliniezi textul și cum faci **liste**;
- cum îți verifici singur documentul cu butonul **Verifică**.

## Ce este un procesor de text?

Un **procesor de text** este o aplicație cu care scriem, modificăm, formatăm și tipărim documente: compuneri, referate, invitații, afișe, scrisori. Exemple: **Microsoft Word**, **LibreOffice Writer**, **Google Docs**.

Un document este format din **paragrafe**. Un paragraf se termină când apeși tasta **Enter**. Titlul unui document este și el un paragraf (de obicei primul).

## Formatarea caracterelor

Se aplică doar **textului selectat** (o literă, un cuvânt, o frază):

| Formatare | Buton | Scurtătură | Exemplu |
|---|---|---|---|
| Aldin (îngroșat) | **B** | Ctrl + B | **text aldin** |
| Cursiv (înclinat) | *I* | Ctrl + I | *text cursiv* |
| Subliniat | U | Ctrl + U | text subliniat |
| Font | lista de fonturi | | Arial, Times New Roman |
| Mărime | lista de mărimi | | 12, 14, 18 (puncte) |
| Culoare | paleta de culori | | text roșu, albastru |

## Formatarea paragrafelor

Se aplică **întregului paragraf** în care se află cursorul, chiar dacă nu ai selectat nimic:

- **alinierea**: la stânga, centrat, la dreapta, stânga-dreapta (justificat);
- **listele**: cu buline (•) sau numerotate (1, 2, 3).

> **Sfat:** întâi scrii tot textul, apoi îl formatezi. Așa nu pierzi timp și documentul arată unitar.

## Pașii formatării

1. Selectezi textul (tragi cu mouse-ul peste el sau dai dublu clic pe un cuvânt).
2. Alegi formatarea din bara de instrumente.
3. Verifici rezultatul; dacă ai greșit, folosești **Anulează** (Ctrl + Z).

## Aplicații interactive

```procesor-text
# Formatează invitația după cerințe, apoi apasă „Verifică”.
Text:
Invitație la Ziua Școlii
Dragi colegi, vă invităm vineri, la ora 12, în sala de festivități.
Programul cuprinde: o scenetă, un concurs de cultură generală și o expoziție de desene.
Vă așteptăm cu drag!
Cerințe:
- titlul: aldin, centrat, mărime 18 | Titlul este aldin, centrat și are mărimea 18
- titlul: culoare roșie | Titlul este scris cu roșu
- „vineri, la ora 12”: subliniat | Data și ora sunt subliniate
- paragraful 3: stânga-dreapta | Paragraful 3 este aliniat stânga-dreapta
- paragraful 4: la dreapta, cursiv | Ultimul rând este aliniat la dreapta și scris cursiv
```

```procesor-text
# Transformă cele trei reguli într-o listă numerotată și scrie tot textul cu fontul Verdana.
Text:
Reguli în laborator
Nu mâncăm și nu bem lângă calculator.
Păstrăm o postură corectă pe scaun.
Facem o pauză scurtă la fiecare 30 de minute.
Cerințe:
- titlul: aldin, centrat
- paragraful 2: listă numerotată
- paragraful 3: listă numerotată
- paragraful 4: listă numerotată
- tot textul: font Verdana | Tot textul folosește fontul Verdana
```

```categorii
# Formatare de caracter sau de paragraf?
Formatarea caracterelor: aldin, cursiv, subliniat, culoarea textului, mărimea fontului
Formatarea paragrafelor: aliniere centrată, aliniere stânga-dreapta, listă cu buline, listă numerotată
```
